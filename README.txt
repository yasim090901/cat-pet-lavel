[EXE 만들기 - 윈도우]
1) Node.js(LTS)를 설치하세요. https://nodejs.org
2) 이 폴더의 build.bat 을 더블클릭 → 끝나면 dist\CatPianoPet.exe 가 생겨요.
   (이 exe 하나만 있으면 어디서든 실행됩니다. 바탕화면/시작프로그램에 두세요)
[바로 실행해 보기] run.bat 더블클릭
[조작]
 - 캐릭터를 좌클릭 꾹 누른 채 끌면 이동
 - 캐릭터가 없는 투명한 부분은 클릭이 그대로 뒤의 창으로 통과
 - 키보드를 칠 때마다(어느 프로그램에서든) 팔이 건반을 침
 - 우클릭 → 종료
[맥/리눅스] 터미널에서 npm install 후 npm start (맥은 입력 모니터링 권한 필요)
[크기] pet.html 의 --s 값과 main.js 의 SCALE 을 같이 바꾸세요.
